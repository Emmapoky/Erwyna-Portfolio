# Erwyna Portfolio

My portfolio site: https://emmapoky.github.io/Erwyna-Portfolio/

One `index.html`, no build step. Open it in a browser or push to `main` and GitHub Pages updates.

## Adding screenshots

| Where it shows | Drop the file here | What happens |
| --- | --- | --- |
| Any project card | `assets/images/<name>.png` | Swap the `src` on that card's `<img>`. |
| Scrolling wheel beside my photo | `assets/images/thumbs/<name>.jpg` | Keep these small (about 720px wide). Add a `<a class="tile">` to either column, in both copies. |

Screenshots look best at 16:10 (for example 1440 x 900).

## Resume

`assets/resume.pdf` is what every resume button links to. Replace that file to update it everywhere, and blur the phone number first since the file is public.
